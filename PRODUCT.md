# Shanghai Afterglow — Product Brief

<!-- This brief is an inferred working contract for the local gallery requested in chat. -->

## Platform

Web, delivered as a portable static page that can be opened locally or served from the project folder.

## Users

The creator exploring City Pop painting prompts and comparing how prompt variables affect the same Shanghai subject.

## Product purpose

Turn the generated Shanghai and Beijing City Pop paintings and their full prompts into an experiment archive that is quick to scan, compare, inspect, and reuse.

## Positioning

An image-led studio wall: every artwork is a visual result, every prompt is an editable hypothesis.

## Operating context

Desktop-first browsing with occasional mobile review. The gallery should remain useful without a backend, login, or build step.

## Core capabilities

- Browse all generated images across five experiment rounds and two cities.
- Filter by round and style direction.
- Read the complete prompt beside the visual result.
- Copy any prompt for another generation pass.
- Open a larger image view without losing context.
- Keep the interface bilingual enough for the existing Chinese prompt archive while using concise English labels where they improve the studio tone.

## Content in scope

- 10 first-round explorations.
- 6 second-round refinements focused on rougher, flatter City Pop mark-making.
- 3 third-round experiments shaped by the supplied reference observations.
- 6 fourth-round local-view experiments that vary Shanghai foreground elements without returning to a Bund panorama.
- 10 fifth-round Beijing local-view experiments that vary historic, waterside, mountain, and modern-CBD fragments.

## Visual direction

Deep cobalt night, violet haze, coral-orange accents, warm paper-white type, and pale citrus highlights. The interface should feel like a carefully pinned proof wall rather than a generic SaaS dashboard.

## Product principles

1. Let the artwork lead.
2. Make prompt variables legible.
3. Keep comparison friction low.
4. Preserve a rough print / studio-notebook character without sacrificing usability.
5. Favor static portability over framework overhead.

## Accessibility and inclusion

Keyboard-accessible controls, visible focus states, meaningful image alt text, sufficient contrast for body copy, and reduced-motion support.
